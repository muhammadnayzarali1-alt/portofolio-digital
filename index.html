Tentang Saya

Halo! Nama saya Muhammad Nayzar Ali, mahasiswa Program Studi Teknik Komputer di Politeknik Negeri Samarinda.

Saya tertarik dengan dunia komputer dan teknologi. Selama kuliah, saya banyak belajar tentang penggunaan aplikasi komputer, pengolahan data, pembuatan dokumen, hingga menyusun presentasi.

Beberapa aplikasi yang pernah saya gunakan antara lain Microsoft Word, Excel, dan PowerPoint. Saya juga senang mencoba hal-hal baru dan menambah pengalaman melalui tugas maupun praktik perkuliahan.

Melalui portofolio ini, saya ingin menampilkan beberapa tugas dan hasil pembelajaran yang telah saya kerjakan selama mengikuti mata kuliah Keterampilan Komputer. Selain sebagai dokumentasi, portofolio ini juga menjadi salah satu cara untuk melihat perkembangan kemampuan saya.

Keterampilan

Teknis

  • Microsoft Word: membuat dan mengatur dokumen, laporan, serta menggunakan fitur Mail Merge.
  • Microsoft Excel: mengolah data, menggunakan rumus dasar, membuat tabel, dan menyusun rekap data.
  • Microsoft PowerPoint: membuat slide presentasi dengan susunan materi dan desain yang menarik.
  • Pengolahan Data: mengumpulkan, memasukkan, mengatur, dan menyajikan data dalam bentuk tabel.
  • Dasar Teknologi Komputer: memahami penggunaan komputer dan beberapa aplikasi pendukung kegiatan perkuliahan.
